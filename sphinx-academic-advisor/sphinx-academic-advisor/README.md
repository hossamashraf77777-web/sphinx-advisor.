# Sphinx FCAI Academic Advising Agent

مشروع مادة Agent-Based Systems - كلية الحاسبات والذكاء الاصطناعي، جامعة سفنكس.
وكيل إرشاد أكاديمي **قائم على القواعد (Rule-Based)** مبني بـ Python و Streamlit.

> **تنبيه مهم:** البيانات الموجودة حالياً في `data/demo/` **بيانات تجريبية** كتبها الفريق لاختبار الواجهة والمنطق.
> أكواد المواد وأسماؤها والمتطلبات السابقة والساعات ولوائح الدرجات والتخرج فيها **ليست رسمية**.
> التطبيق يعرض تحذيراً ظاهراً في كل صفحة طالما يستخدم بيانات تجريبية.

## الوكيل لا يستخدم ML أو LLM
كل قرار ناتج عن قواعد مكتوبة في `agent/rules.py`. كل قرار يحتوي على: **اسم القاعدة + النتيجة + شرح مفهوم**.
النتائج الثلاث الممكنة: `passed` (القاعدة متحققة) / `failed` (غير متحققة) / `needs_verification` (معلومة أو لائحة ناقصة، فلا يخمّن الوكيل).

## الهيكل

```
app.py                  نقطة البداية + القائمة الجانبية
config.py               وضع البيانات (demo / official) والمسارات
pages/                  الصفحات السبع (واجهة فقط)
ui/                     مكونات الواجهة المشتركة + تحميل CSS
agent/                  القواعد والأهلية والتوصيات والتخرج (بدون Streamlit)
services/               قراءة الملفات + التحقق + حساب الـ GPA (بدون Streamlit)
data/demo/              بيانات تجريبية      data/official/   البيانات الرسمية (فارغة، ومستبعدة من Git)
styles/main.css         كل التصميم في ملف واحد
tests/                  اختبارات pytest
```

## التشغيل بدون تثبيت أي شيء على جهازك

### الطريقة 1: GitHub Codespaces (للتجربة والتعديل)
1. أنشئ حساباً على github.com، ثم مستودعاً (Repository) جديداً وارفع إليه محتوى هذا المجلد (زر **Add file > Upload files**).
2. من صفحة المستودع: **Code > Codespaces > Create codespace on main**. ينفتح محرر في المتصفح.
3. في الـ Terminal داخل المحرر اكتب:
   ```
   pip install -r requirements.txt
   streamlit run app.py
   ```
4. سيظهر إشعار لفتح المنفذ (port 8501): اضغط **Open in Browser**.

### الطريقة 2: Streamlit Community Cloud (رابط للعرض أمام الدكتور)
1. ارفع المشروع إلى GitHub كما في الأعلى.
2. ادخل share.streamlit.io بحساب GitHub، اضغط **Create app**، واختر المستودع والفرع، واكتب `app.py` كملف رئيسي، ثم **Deploy**.
3. استخدم مستودعاً **عاماً للبيانات التجريبية فقط**. لا ترفع بيانات الطلاب الحقيقية إلى مستودع عام.

(أسماء الأزرار قد تختلف قليلاً مع تحديث هذه المواقع.)

### التشغيل على جهازك (اختياري)
```
pip install -r requirements.txt
streamlit run app.py
```
وللاختبارات: `python -m pytest`

## كيف تغيّر التصميم
- **الألوان والخطوط والمسافات وحواف المكونات:** القسم 1 فقط في `styles/main.css` (متغيرات مثل `--primary-color` و `--secondary-color`).
- **قيد معروف:** ثيم Streamlit الأساسي (`.streamlit/config.toml`) وألوان الرسوم (`config.py` > `CHART_COLORS`) لا يقرآن متغيرات CSS.
  لذلك عند تغيير اللون الأساسي عدّله في 3 أماكن: `main.css` و `.streamlit/config.toml` و `CHART_COLORS`.
- **صفحة جديدة:** أنشئ ملفاً في `pages/` وابدأه بـ `ds = start_page("العنوان", "وصف")`، ثم أضف سطر `st.Page(...)` في `app.py`.

## كيف تضيف البيانات الرسمية
1. ضع `courses.csv` و `student.json` و `regulations.json` في `data/official/` (الصيغة الدقيقة في `data/official/README.md`).
2. شغّل التطبيق مع المتغير `SPHINX_DATA_MODE=official`.
3. أي لائحة غير متوفرة اتركها `null` ولا تخمّنها. سيقول الوكيل "needs verification".
4. إذا كان أي ملف ناقصاً يظهر خطأ واضح، **ولا يعود التطبيق للبيانات التجريبية بصمت**.

## قرار التخزين
CSV + JSON بدل SQLite: بيانات المنهج للقراءة غالباً، ويمكن لأي عضو في الفريق فتحها وتصحيحها في Excel، وتظهر تغييراتها بوضوح في Git.
الملف `services/data_loader.py` هو الوحيد الذي يقرأ الملفات، فيمكن استبداله بقاعدة بيانات لاحقاً دون تغيير الوكيل أو الصفحات.

## ما الذي تم اختباره فعلياً
- **اختبارات pytest (54 اختباراً):** حساب الـ GPA، قواعد المتطلبات السابقة، سقف الساعات، التوصيات، خطة التخرج، تحميل الملفات والتحقق منها. نجحت كلها.
- **تشغيل كل الصفحات بنسخة وهمية من Streamlit:** للتأكد من عدم وجود أخطاء في كود Python نفسه.
- **لم يُشغَّل التطبيق على Streamlit الحقيقي في بيئة التطوير** (لم يكن التحميل من الإنترنت متاحاً هناك)، ولم يُفحص التصميم بصرياً في متصفح.
  شغّله مرة واحدة قبل التسليم، وأخبرنا بأي خطأ أو أي شيء يبدو غريباً في الشكل.
